# 🚀 AI Career & Skill Analyzer

An AI-powered career and skill analysis platform that helps users identify their skill gaps and create a personalized learning roadmap.

## ✨ Features

- 🔐 User Registration & Login
- 👤 User Profile Management
- 🎯 Career Goal Selection
- 📊 Skill Gap Analysis
- 🐍 Python-based Skill Analysis
- 🗺️ Personalized Learning Roadmap
- 📈 Progress Tracking

## 🛠️ Tech Stack

### Backend
- Node.js
- Express.js
- JavaScript

### Database
- MongoDB
- Mongoose

### Python Service
- Python
- FastAPI

### Frontend

- CSS
